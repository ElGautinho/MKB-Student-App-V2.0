# MKB Student Survey — Photo Sources

> **Repository notice:** This file is maintainer documentation for the image assets used by the theme. The application itself is a WordPress LMS with role-based dashboards, surveys, profiles, private chat, and notifications.

The LMS theme uses African student/education photography from Pexels. Pexels content is free for personal and commercial use under the Pexels license. Photographer attribution is appreciated.

Note: the current Canva integration can search Canva designs/templates, but it does not expose Canva's stock-photo asset library as downloadable files for direct packaging into a WordPress ZIP. The selected Pexels pages explicitly support editing in Canva, so the imagery can be further edited in Canva if desired. The footer no longer displays a Pexels credit; this file remains the source record for maintainers.
