# Survey images and student feedback

> **Repository notice:** This document covers survey images and feedback for users of the `student-survey-lms` theme. The same repository also contains role-based dashboards, private chat, profile avatars, and unread notifications.

## Ajouter une image à un Survey

1. Dans WordPress, connectez-vous avec un compte **Instructor** ou **Administrator**.
2. Ouvrez **Surveys → Add New** (ou modifiez un Survey existant).
3. Saisissez le titre, la description et les dates comme d'habitude.
4. Dans la colonne droite de l'éditeur, cherchez **Featured Image / Image mise en avant**.
5. Cliquez sur **Set featured image / Définir l’image mise en avant**.
6. Importez une image depuis votre ordinateur ou choisissez-en une dans la médiathèque.
7. Publiez ou mettez à jour le Survey.

Cette image devient automatiquement la couverture du Survey dans la liste des Surveys et sur la page où l'étudiant répond.

Si aucune image n'est définie, le thème utilise automatiquement son image d'éducation africaine de secours.

## Page My Feedback

Une page **My Feedback** est créée automatiquement. Elle apparaît dans le menu des étudiants à côté de **Completed Surveys**.

Elle affiche, pour chaque réponse de l'étudiant :

- la couverture du Survey ;
- le titre et la description ;
- l'Instructor / créateur du Survey ;
- le nombre de questions ;
- les dates de disponibilité ;
- la date à laquelle l'étudiant a répondu ;
- le feedback complet de l'Instructor ;
- un état **Received** ou **Waiting for review**.

L'étudiant ne peut voir que ses propres réponses et feedbacks.

## Chat et notifications

Les étudiants peuvent choisir un Instructor dans la page **Chat** et lui envoyer des messages privés. Les Instructors peuvent choisir un Student ou un Administrator depuis leur espace Chat. Le bouton de notifications dans l’en-tête indique les nouveaux Surveys, feedbacks, réponses et messages non consultés.
